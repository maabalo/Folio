      # readme

      What is Folio?

      Folio lets you look inside files without opening them in Word, Excel, a PDF reader or any other app. Open one file or a whole folder, click through them, and see each file's contents and details in one place.

      It's useful for finding the right file in a messy folder, checking what an attachment contains, or reading a file you don't have the software for. Everything happens on your device, and nothing is uploaded.

      01 quick start 02 preview & details 03 supported files 04 shortcuts 05 privacy 06 tips & limits

      01 Quick start

      1. Open files. Click open (or press O), click the folder icon to open a whole folder, or drag files and folders anywhere onto the page.
      2. Pick a file. Everything you open is listed in the Explorer on the left. On a phone, tap ☰ to show it.
      3. Look inside. The Preview tab shows the contents. Switch to Details for facts about the file.
      4. Tidy up. Hover a file and click × to remove it, or click clear to remove all of them.

      02 Preview & Details

      Preview
      The file's contents: pages of a PDF, a formatted Word document, spreadsheet sheets, a playable video, and so on.
      Details
      Name, type, size and dates, plus facts about the contents (page or word counts, image size, video length), document properties such as the author, and a SHA-256 checksum.

      The checksum is a fingerprint of the file. If two files have the same checksum, they are identical.

      03 Supported files

      Documents
      PDF, Word (.docx), Markdown, HTML
      Spreadsheets
      Excel (.xlsx, .xls), OpenDocument (.ods), CSV, TSV
      Presentations
      PowerPoint (.pptx), text of each slide
      Code & text
      .txt, .json, .js, .py, .css, .sql, .yml, logs and more
      Images
      PNG, JPG, GIF, WebP, SVG, AVIF, BMP, ICO
      Media
      MP4, WebM, MOV, MP3, WAV, M4A, FLAC, OGG
      Archives
      ZIP: lists the files inside
      Anything else
      Raw data view and a guess at the real format

      05 Privacy

      • Your files never leave your device. They are read by your browser and never sent anywhere.
      • Nothing is kept. Reloading or closing the page clears the list. Folio only remembers your Light/Dark choice.
      • Some formats need the internet once. Word, Excel, PowerPoint, PDF, Markdown and ZIP use small viewer libraries downloaded the first time. Your files are not part of that download.

      06 Tips & limits

      • Type in the filter box above the list to find a file by name or folder.
      • Very large files show their raw data instead of a full preview, so the page stays fast.
      • Old Word (.doc) and PowerPoint (.ppt) files can't be previewed. Save them as .docx or .pptx first.
      • PowerPoint previews show the text of each slide, not the design.
      • HEIC and TIFF photos only display in Safari.
      • If a preview fails, click try again. If it keeps failing, check your internet connection.
      • Change between Light, Dark and Auto in Settings (the sliders icon).
